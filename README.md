# SingStar Theme for UltraStar Deluxe

A SingStar-inspired theme for [UltraStar Deluxe (USDX)](https://github.com/UltraStar-Deluxe/USDX).

## Install

1. Copy `SingStar.ini` and the `SingStar/` folder into the game's `themes` directory. In the USDX source tree, this is
   `game/themes/`.
2. Start the game and choose **Options → Themes → SingStar**.
